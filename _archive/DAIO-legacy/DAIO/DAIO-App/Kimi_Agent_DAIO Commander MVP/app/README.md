# DAIO Commander MVP

**Digitale Asset-Inheritance Orchestration** - Die erste vollstaendige Loesung fuer digitale Erbfolge-Planung in Deutschland.

## WICHTIG: Erste Schritte

### Windows
1. Stellen Sie sicher, dass **Node.js** installiert ist: https://nodejs.org
2. Doppelklicken Sie auf **START.bat**
3. Warten Sie, bis die Installation abgeschlossen ist (erster Start dauert ca. 2-3 Minuten)

### macOS / Linux
1. Stellen Sie sicher, dass **Node.js** installiert ist: https://nodejs.org
2. Oeffnen Sie ein Terminal im DAIO-Commander Ordner
3. Fuehren Sie aus: `./start.sh`
4. Warten Sie, bis die Installation abgeschlossen ist

## Features

### Big Five Asset-Klassen
1. **Bitcoin (BTC)** - Vollstaendige Wallet-Erfassung
2. **Ethereum (ETH)** - Inkl. Smart Contract-Check
3. **Stablecoins (USDC/USDT/DAI)** - Nach Plattform kategorisiert
4. **NFTs** - Manuelle Validierung mit Utility-Nachweis
5. **Gaming-Assets** - AGB-konforme Liquidationsstruktur

### Global Loss Estimator
- Echtzeit-Berechnung basierend auf 50 Demo-Faellen
- Hochrechnung fuer Deutschland: 47 Mrd EUR jaehrliche Verluste
- Potenziell gerettet: 33 Mrd EUR durch DAIO
- Interaktive Visualisierungen

### White-Label Support
- Toggle zwischen Back2IQ und F&P Kapitalstrukturen Branding
- Template-Generator fuer druckfertige Dokumente

## Fehlerbehebung

### "Node.js nicht gefunden"
Laden Sie Node.js von https://nodejs.org herunter und installieren Sie es.

### "npm install fehlgeschlagen"
Pruefen Sie Ihre Internetverbindung und fuehren Sie START.bat erneut aus.

### Anwendung startet nicht
Loeschen Sie den Ordner "node_modules" und starten Sie erneut.
