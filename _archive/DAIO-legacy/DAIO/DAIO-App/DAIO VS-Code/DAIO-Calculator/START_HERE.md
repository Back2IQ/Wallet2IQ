# 🚀 Back2IQ - Ahead by Design
## DAIO Value Explorer - Schnellstart-Anleitung

### 📋 Voraussetzungen
- **Node.js** (Version 18 oder höher) - [Download hier](https://nodejs.org/)

### 🎯 Schnellstart (One-Click)

**Option 1: PowerShell Script (Empfohlen)**
- Doppelklick auf `start-app.ps1`

**Option 2: Windows Batch File**
- Doppelklick auf `start-app.bat`

### 🔄 Manueller Start
```bash
# 1. Dependencies installieren
npm install

# 2. Entwicklungsserver starten
npm run dev
```

### 🌐 Zugriff auf die App
Die Anwendung ist verfügbar unter: **http://localhost:5173**

### 🛠️ Weitere Befehle
```bash
# Für Production build
npm run build

# Vorschau des Production builds
npm run preview

# Code linten
npm run lint
```
